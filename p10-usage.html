三种用法与掩码

同一个注意力函数，在模型里被用了三次，每次的 Q、K、V 来自不同地方。 这一节只有三段，却是最容易混淆的地方——尤其是“掩码”。

为什么学这一页
论文位置§3.2.3
不学卡在哪三种注意力（编码器自注意力、掩码自注意力、交叉注意力）分不清，也不知道掩码怎么加。
它解决什么这三处用法就是整个架构的接线方式，搞混了就看不懂数据在编码器和解码器之间怎么流。

1同一函数，三种接线方式

交叉注意力encoder-decoder attention§3.2.3 第 1 条

是什么：Q 来自解码器，K 和 V 来自编码器输出的注意力。它是整个模型里唯一连接左右两半的通道。

直观看：生成英文 “animal” 时，解码器拿自己的状态去问“原文里哪个词跟我有关”， 然后在“这只”“动物”上拿到高权重，把它们的语义取过来。

为什么 K 和 V 同源：因为它们都描述“原文有什么”。Q 描述“我现在需要什么”，来自另一侧。

易错：交叉注意力里没有掩码（编码器输出没有“未来”的概念）。有掩码的只有解码器自己的自注意力。

2掩码：不许偷看未来

原文的说法是：“We need to prevent leftward information flow in the decoder to preserve the auto-regressive property. We implement this inside of scaled dot-product attention by masking out (setting to −∞) all values in the input of the softmax which correspond to illegal connections.”

拆成三句：目标是保住自回归性质；手段是把非法连接的分数设成 −∞；位置是在 softmax 的输入上。

掩码masking§3.2.3；图 2

是什么：一张与分数矩阵同形状的“禁止表”。被禁止的位置在 softmax 之前被替换成 −∞。

为什么是 −∞ 而不是 0：因为 softmax 会取指数，e−∞=0，权重自然变成 0； 如果设成 0，e⁰=1，反而会分到不小的权重。

效果：softmax 之后，这些位置的权重精确为 0，且整行仍然和为 1（剩下的位置重新分配）。

易错：掩码必须在 softmax 之前。放到之后只能“手动清零”，会破坏归一化（行和不再为 1）， 而且梯度反传时会出问题。
1构造因果掩码4 步
输入
序列长度 n
条件
只在解码器的自注意力里用；编码器和交叉注意力不加
步骤 1
建一个 n×n 的矩阵，元素 (i, j) 表示“位置 i 能否看位置 j”
步骤 2
规则：j ≤ i 允许，j > i 禁止（行号 = 当前词，列号 = 被看的词）
步骤 3
允许处填 0，禁止处填 −∞（实现上常写成 scores + mask，mask 为 0 或 −1e9）
步骤 4
把掩码加到缩放后的分数上，再 softmax
结果
一个上三角被“挖空”的权重矩阵：每行只有前 i 个位置有权重
易错
① 方向搞反（把下三角挖掉，等于只能看未来）； ② 用了 −1e9 之外的极小值导致 ex 下溢成 0 后再除零；③ 忘了对角线要保留（自己可以看自己）。

为什么必须这样做

训练时为了并行，整句译文是一次性喂进解码器的。如果不加掩码，预测第 3 个词时模型能直接看到第 4、5 个词—— 它只要把答案抄过来，损失立刻降到接近 0，什么也学不到。而推理时没有“未来”可抄，模型就崩了。

换句话说：掩码不是在限制模型，而是在让训练时的情形与推理时一致。

3另一种掩码：填充掩码

论文正文没有专门讲它，但任何实现都必须处理——这就是 padding mask。

一个批次里句子长短不一，短的要在末尾补 <pad> 凑齐长度。这些占位符没有任何语义， 如果让它们参与注意力，会污染真实位置。做法与因果掩码类似：把所有 pad 所在列设为 −∞。

作用对象解码器自注意力所有注意力（编码器、解码器、交叉）
屏蔽什么未来位置（j > i）pad 占位符
形状n×n 上三角按 batch 里的实际长度，逐样本不同

一个真实的坑：如果一个位置整行都被掩掉（比如整句都是 pad），softmax 会出现 0/0 = NaN。 工程实现里要给这种行加保护（例如把对角线强制设为可见）。论文没有讨论，但写代码一定会遇到。

注意两件事：① 第一个注意力有掩码，第二个没有；② 第二个注意力的 K/V 来自编码器， 而不是上一层的输出——这是整张架构图里唯一一条跨左右两半的连线。

本页要点

  1. 三种用法只差 Q/K/V 的来源：自注意力（同源）、交叉注意力（Q 来自解码器，K/V 来自编码器）。
  2. 只有解码器的自注意力需要因果掩码；交叉注意力不需要。
  3. 掩码的做法是把非法位置的分数设为 −∞，且必须在 softmax 之前。
  4. 掩码的目的是让训练时的并行与推理时的逐步生成保持一致，防止抄答案。
  5. 工程上还有填充掩码，处理批次内的占位符；整行被掩时要防止 NaN。

5自测

Q1掩码值为什么设成 −∞ 而不是 0？
softmax 是指数归一化。要让权重恰好为 0，输入必须是 −∞（实现中用 −1e9 近似）。
Q2下面哪一种注意力不需要因果掩码？
交叉注意力看的是完整的原文，没有“未来”的概念，所以不需要因果掩码（但可能需要填充掩码）。
Q3如果训练时忘了加因果掩码，会发生什么？
模型会学会“抄下一个词”，训练损失接近 0。但推理时没有未来可抄，输出就崩了。这是最典型的“训练-推理不一致”事故。
