1三个评判标准

原文开头就把标准摆出来了，一共三条（“three desiderata”）：

  1. 每层的计算复杂度——算一次要多少运算。
  2. 可并行度——用“最少需要多少个串行操作”来衡量。
  3. 最大路径长度——任意两个位置之间，信号要走多少步。
串行操作数sequential operations§4；表 1

是什么：把计算画成依赖图，最长的那条链上有多少个操作。它衡量“最快也要几步才能算完”。

为什么不用“时间”衡量：时间是硬件相关的，换个 GPU 就变了；串行步数是算法固有的，与硬件无关。

易错：串行操作数 = O(1) 不代表快。它只说明“不排队”，实际耗时还取决于总运算量。自注意力的总运算量是 O(n²·d)，可能更大。
最大路径长度maximum path length§4；表 1

是什么：前向信号或反向梯度，在两个位置之间经过的最少边数。

为什么重要：路径越长，梯度要穿过的非线性越多，越容易消失；同时模型越难“对准”这两个位置的关系。 论文原话：路径越短，越容易学长距离依赖。

易错：路径长度是层内的度量，不是“句子里的距离”。它衡量的是网络结构，不是语言学距离。

2表 1 逐行拆解

层类型每层复杂度串行操作最大路径长度
自注意力O(n² · d)O(1)O(1)
循环（RNN）O(n · d²)O(n)O(n)
卷积（CNN）O(k · n · d²)O(1)O(logk n)
受限自注意力O(r · n · d)O(1)O(n/r)

n = 序列长度，d = 表示维度，k = 卷积核大小，r = 邻域大小。来自论文表 1。

自注意力：O(n²·d)

每个词要和每个词算一次点积，n 个词就是 n² 次；每次点积的代价是 d。所以是 n²·d。 这就是著名的“平方复杂度”——也是它最大的软肋。

循环：O(n·d²)

每步做一次 d×d 的矩阵乘法，代价 d²；共 n 步。所以是 n·d²。 注意它没有 n² 项——长序列时反而比注意力省。

卷积：O(k·n·d²)

每个位置要做 k 个位置的卷积，每个卷积是 d×d 的运算。比循环还贵 k 倍，但可以并行。

受限自注意力：O(r·n·d)

只让每个词看左右 r 个邻居，不算全表。复杂度降到线性，但路径长度变成 O(n/r)——牺牲了“一步到位”。

3到底谁更便宜？取决于 n 和 d 的关系

比较 O(n²·d) 和 O(n·d²)：约掉一个 n，就变成比较 n 和 d。 也就是说，当序列长度小于表示维度时，自注意力更便宜；反过来则更贵。

序列长度 n（d=512）自注意力 n²·d循环 n·d²谁更省
1005.1 M26.2 M注意力省 5 倍
512134 M134 M持平
1000512 M262 M循环省一半

论文的判断是：在翻译任务里 n 通常小于 d（句子几十个词元，维度 512），所以自注意力又快又并行， 是压倒性的优势。这也解释了为什么它先在 NLP 落地，而不是先用在长文档或高分辨率图像上。

4那张表真正想说的三件事

  1. 并行性不是“稍好”，是量级差异。RNN 的串行步数是 O(n)，自注意力是 O(1)。 在硬件上，这意味着 GPU 利用率差几十倍——不是常数优化能弥补的。
  2. 路径长度是“能不能学会”的问题。RNN 的 O(n) 让长距离依赖天生难学；O(1) 让它变成和一个普通局部关系同样容易。
  3. 代价是明码标价的。作者没有藏着 O(n²)，反而自己写了：长序列时会考虑“受限自注意力”（只看邻域 r）， 把复杂度降到 O(r·n·d)。

这段话其实预言了之后五年的研究：“To improve computational performance for tasks involving very long sequences, self-attention could be restricted to considering only a neighborhood of size r … We plan to investigate this approach further in future work.” 后来 Longformer、BigBird、稀疏注意力全是这条路。

5一个“顺带的”好处：可解释性

原文最后一段说：自注意力可能带来更好的可解释性，因为可以检查注意力分布， 而且不同头明显学到了不同的任务，很多与句法、语义结构相关。

注意它的措辞是 “could yield”——可能。论文附录给了可视化，但没有做任何定量论证。 后来的研究也发现：注意力权重高不等于因果重要，不能直接当解释用。

别被二手资料带偏：“Transformer 可解释”是一个常见但过强的说法。 正确说法是：它提供了一种可检查的中间量（注意力权重），但这个量是否等于“模型的理由”，仍有争议。

本页要点

  1. 三个标准：每层复杂度、串行操作数、最大路径长度。
  2. 自注意力 O(n²·d) / O(1) / O(1)；RNN O(n·d²) / O(n) / O(n)；CNN O(k·n·d²) / O(1) / O(logk n)。
  3. 谁更省取决于 n 与 d 的大小：n < d 时自注意力更便宜，这也符合翻译任务的实际情况。
  4. 代价是平方复杂度，作者自己提出了“受限自注意力”作为长序列的出路。
  5. 可解释性只是“可能”，论文没有论证，不能当成结论。

6自测

Q1d=512、n=256 时，自注意力和循环网络谁的每层计算量更大？
256²×512 ≈ 33.5M，256×512² ≈ 67.1M。n < d 时自注意力更省，分界点正是 n = d。
Q2“串行操作数 O(1)” 意味着什么？
它衡量的是依赖深度，不是工作量。自注意力的依赖深度是 1，但工作量是 n²·d。
Q3论文对“长序列”提出的折中方案是？
表 1 第 4 行。用局部性换线性复杂度，代价是路径变长。后来的稀疏注意力、滑窗注意力都是这个思路。
