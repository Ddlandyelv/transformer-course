13正文·§3.5

位置编码：给词排座位

自注意力有一个致命的盲区：它看不见顺序。「猫追狗」和「狗追猫」在它眼里是同一个集合。 这一页讲清楚这个盲区从哪来，以及正弦波是怎么补上它的。

为什么学这一页
论文位置§3.5 式(3)(4)
不学卡在哪注意力本身没有顺序概念，不知道模型凭什么知道“谁在第几位”。
它解决什么没有它，模型会把一句话当成一袋词，「猫追狗」和「狗追猫」完全一样。

1为什么自注意力“看不见顺序”

看式 (1)：softmax(QKT/√dk)V。这里面全是矩阵乘法、点积、softmax， 没有任何一步依赖“第几个位置”。

更严格地说：如果把输入的 n 个词打乱顺序，输出的 n 个向量只会跟着同样打乱—— 输出与输入是“等变”的。模型无法从表示中区分“谁在前谁在后”。

输入没有位置编码时，模型看到的东西
猫 追 狗同一个向量集合，只是排列不同
“谁追谁”这层关系完全丢失
狗 追 猫
位置编码positional encoding§3.5、式 (4)

是什么：一个只取决于位置、与内容无关的向量 PE(pos)。把它加到词向量上， 让“第几个词”这个信息进入表示。

为什么用加法而不是拼接：拼接会把维度变成 1024，破坏残差的形状约束； 加法保持 512 维，简单且够用。代价是位置信息与语义信息混在同一个向量里，但模型能学会分离。

易错：位置编码不是“词向量的一部分”，它是在嵌入之后、进入第一层之前加上去的。 编码器和解码器都要加。

2公式：512 条不同频率的正弦波

先看这串数是怎么排出来的：

PE(pos, 2i) = sin( pos / 100002i/dmodel )    PE(pos, 2i+1) = cos( pos / 100002i/dmodel ) 式 (4)。偶数维用 sin，奇数维用 cos；i 是维度序号（0 ≤ i < dmodel/2）

注意分母：100002i/d_model 是一个随 i 增长的数。i 越大，分母越大， 正弦的“角速度”越慢。于是：

  • 低维（i 小）：分母接近 1，波长约 2π，位置每加 1 就转一大圈——变化极快。
  • 高维（i 大）：分母接近 10000，波长约 10000·2π ≈ 62832——在几百个位置内几乎是一条直线。
  • 波长构成一个等比数列，从 2π 到 10000·2π。
1手算一个位置编码值4 步
输入
位置 pos = 1，维度序号 i = 0（即第 0 维），dmodel = 512
条件
偶数维用 sin，奇数维用 cos；同一对 (2i, 2i+1) 共用同一个分母
步骤 1
算分母：100002×0/512 = 100000 = 1
步骤 2
算角度：pos / 分母 = 1 / 1 = 1 弧度
步骤 3
取 sin：sin(1) ≈ 0.841（这就是第 0 维的值）
结果
PE(1, 0) ≈ 0.841；同位置的第 1 维是 cos(1) ≈ 0.540
易错
① 把 2i/dmodel 写成 i/dmodel（分母会算错一半）； ② 用角度制而不是弧度制；③ 以为每维都有独立的频率——实际是每一对维共用一个频率。

高维到底有多慢

第 40 维（i=20）≈ 2.050.4870.468

所以这个 512 维向量像一台混合进制的计数器：低位飞快翻转，高位几乎不动。 每个位置因此得到一个独一无二的“指纹”，而且相邻位置的指纹很像，远处的差别大。

3为什么用正弦，而不是直接编号

最朴素的做法是给每个位置一个整数 1、2、3……但有两个问题：

  • 无界。位置 1000 的值比位置 1 大 1000 倍，会压制词向量，而且模型没见过的长度会直接崩。
  • 没有相对关系。整数之间只有大小，没有“距离相同”的结构。而语言关心的是相对位置（“往前 3 个词”）。

关键性质：相对偏移可以写成线性变换

论文说：“for any fixed offset k, PEpos+k can be represented as a linear function of PEpos.”

原因来自三角恒等式：sin(a+b) = sin a cos b + cos a sin b。 也就是说，位置 pos+k 的那一对 (sin, cos)，可以由位置 pos 的那一对，乘以一个只与 k 有关的旋转矩阵得到。

[ sin(ω(pos+k)) ] = [ cos(ωk) sin(ωk) ] [ sin(ω·pos) ]
[ cos(ω(pos+k)) ] [ −sin(ωk) cos(ωk) ] [ cos(ω·pos) ] 旋转矩阵只依赖 k，与 pos 无关——所以模型可以用同一套操作处理任意距离

这带来一个实用后果：模型很容易学会“看相对位置”这种操作，而不必对每个绝对位置单独记忆。

另一个理由：可以外推

正弦编码是公式生成的，不依赖训练时见过的最大长度。训练时最长 100 个词，推理时给 200 个词， 公式照样能算出值。可学习的位置向量就不行——超出词表范围就没有参数了。

但作者很诚实：表 3 第 (E) 行显示，换成可学习的位置嵌入，结果几乎一样（dev BLEU 25.7 vs 25.8）。 所以“正弦更好”并没有被实验证明，它只是更方便外推。这一点经常被二手资料夸大。

4几个常见追问

为什么编码器和解码器用同一套公式？

因为位置编码与语言无关，只描述“第几个”。两边独立计算即可，不需要共享参数（它本来就没有参数）。

位置编码会被训练吗？

不会。它是固定公式算出来的常量，不参与梯度更新。整个模型里唯一“免费”的信息就是它。

为什么是 10000 这个数？

论文没有解释。它决定了最长有效波长：10000·2π ≈ 62832，远大于任何实际句子长度， 保证在常用范围内不会出现“两个位置编码撞车”。后来的实现大多沿用 10000。

后来有什么改进？

可学习的绝对位置（BERT）、相对位置偏置（T5）、旋转位置编码 RoPE（把位置做成旋转施加到 Q/K 上， LLaMA 等在用）、ALiBi（用距离惩罚代替编码）。它们要解决的问题都一样：让模型知道相对距离，并能外推。

本页要点

  1. 自注意力对顺序不敏感（置换等变），必须显式注入位置信息。
  2. 做法是把一个只与位置有关的 512 维向量加到词嵌入上。
  3. 每个维度一对 sin/cos，频率按等比数列从 2π 到 10000·2π。
  4. 低维变化快、高维变化慢，合起来构成每个位置的唯一“指纹”。
  5. 选正弦的理由是相对位置可线性表示 + 可外推；实验上与可学习版本几乎持平。

没有位置编码仍能训练、也能做词袋级别的任务，只是学不到语序相关的关系。它是“能力缺失”，不是“训练失败”。
