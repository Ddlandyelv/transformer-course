# Attention Is All You Need · 逐节精读

一套把 Transformer 原论文拆成 24 个独立页面的中文交互教程。每页只讲一件事，讲透为止。

原文：*Attention Is All You Need*，Vaswani et al., NIPS 2017，[arXiv:1706.03762](https://arxiv.org/abs/1706.03762)

## 这套课解决什么问题

读 Transformer 论文最常见的困境不是"不够聪明"，而是三个断点：

- **符号断点**：`Q`、`K`、`V`、`d_model`、`√d_k` 大量出现，却不解释为什么长这样。
- **前置断点**：论文假设你已知词嵌入、softmax、编码器-解码器、BLEU——这些在 2017 年是常识，对今天的初学者不是。
- **顺序断点**：论文按"结论先行"的学术写法，第 3 章一口气讲完所有组件。

所以这套课做了三件事：把前置知识单独抽出来讲、把正文按零件拆开重排、给每个术语标注它在论文里出现的位置。

## 结构

| 分组 | 页面 | 说明 |
|---|---|---|
| 第零幕 · 从零开始 | 0.1 – 0.5 | 不出现公式。从"为什么不能写语法规则"讲到"为什么需要注意力" |
| 第一部分 · 前置知识 | 01 – 04 | 向量矩阵、神经网络与训练、序列建模、语言模型与指标 |
| 第二部分 · 论文正文 | 05 – 16 | 对应摘要到 §7，逐节精读 |
| 附录 | 17 – 18 | 术语总表与公式速查、学习进度与掌握度 |

每个内容页固定包含：**为什么学这一页**（论文位置 / 不学卡在哪 / 它解决什么）→ 核心论点 → 名词定义卡 → 操作卡 → 小结 → 自测。

## 交互组件

点积逐项相乘、矩阵乘法逐格溯源、softmax 滑块、BPE 合并分步、注意力弧线、多头切换、缩放点积五步演算、位置编码热力图、因果掩码开关、学习率曲线、RNN 逐步传递、复杂度曲线、逐词解码。

自测共 138 道，答对答错都会记录，第 18 页汇总成掌握度看板与错题本。
