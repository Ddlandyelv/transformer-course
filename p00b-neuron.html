一个神经元：模型里最小的零件

Transformer 有 6500 万个参数，但它们全都长在同一个零件上：神经元。 这一页只干一件事——把这一个零件拆开，用真实数字算给你看。 看懂之后，"权重、偏置、激活、层、参数"这五个词就都有落点了。

前置：0.1 为什么不能写规则 用于：§3.3 FFN、§3.1 残差 约 20 分钟
为什么学这一页
论文位置§3.3 式(2)；§3.1 每个子层
不学卡在哪§3.3 说“两次线性变换夹一个 ReLU”，不知道这两步各在干什么；看到 512→2048→512 只当成数字游戏。
它解决什么FFN 占了模型三分之二的参数，不懂神经元就无法理解这三分之二在做什么。

1它只做四件事

一个神经元接收几个数字，吐出一个数字。中间只经过四个动作，没有任何别的机关：

1收信号输入
收到什么
几个数字，记作 x₁, x₂, …, xₙ。可以理解为"几个观察到的信号"。
2各自乘一个权重，再全加起来加权求和
做什么
x₁×w₁ + x₂×w₂ + … + xₙ×wₙ
权重是什么
每个信号配一个数字 w。它表示"这个信号有多重要"。w 是学出来的，不是人定的。
3加一个偏置调门槛
做什么
总和再 + b。b 叫偏置（bias），一个数字。
它管什么
不管输入是什么，先给一个基础分。b 是负数就是"提高门槛"，b 是正数就是"降低门槛"。
4过一道门槛，吐出结果激活
做什么
把上一步的数丢进一个固定函数 f，得到输出。
最常用的 f
ReLU：f(t) = max(0, t)。正数原样通过，负数一律归零。

合起来就一行：输出 = f( x₁w₁ + x₂w₂ + … + b )。整篇论文里所有"神经网络"的部分， 拆到最底层都是这一行，重复几百万次。

2手算一次：判断这句话是不是疑问句

下面用两个信号、三个参数走一遍。每点一次「下一步」，只发生一件事——先乘权重，再求和，再加偏置，最后过门槛。

用两个信号、三个参数，把这个神经元搭出来，然后拿四个句子试。

先定输入

信号含义取值
x₁句末有问号吗有 = 1，没有 = 0
x₂句子里有「吗 / 呢 / 吧」吗有 = 1，没有 = 0

再定参数

参数取值这个值意味着什么

第三、四行是故意的：拿掉问号只剩「吗」，或者拿掉「吗」只剩问号，都凑不够 2.5 分。 这正说明偏置在控制门槛——参数调成这样，这个神经元的规则就是"两个证据都齐才算疑问句"。

换个参数，规则就变了。如果 b 改成 −1.0，那么"只有问号"（得 2.0 − 1.0 = 1.0）也会判为疑问句。 如果 w₁ 改成 1.0，那么问号的份量就和「吗」差不多。 所有"模型的行为"，本质都是这些数字的位置。训练要做的，就是找到一组位置，让整体表现最好。

注意最后一行的处理：ReLU 把 −0.5 和 −2.5 都压成了 0。这两个负数原本差别很大，经过 ReLU 之后看起来一样了。 这不是 bug，是有意为之：负数意味着"证据不足"，证据不足就是"不发声"。 至于不足多少，后面的层并不关心。

3三个名词，现在有了具体所指

权重weight，记作 w§3.3 式(2) 的 W₁、W₂

是什么：每个输入信号配的那个倍数。上面的例子里是 w₁=2.0、w₂=1.5。

它在决定什么：这个信号有多重要。w 越大的信号，对输出影响越大。

它从哪来：训练学出来的，人只给初始值（随机）。

易错：权重不是"重要性打分"，它是在具体任务里的系数。换一个任务，同一个信号可能需要完全不同甚至相反方向的 w。
偏置bias，记作 b§3.3 式(2) 的 b₁、b₂

是什么：求和之后加的那个常数。例子里是 −2.5。

为什么不能省：没有 b，输出就永远正比于输入，神经元只能表达"过原点"的关系。 加了 b，才能表达"输入是 0 但依然要输出某个值"这类情况。例子里，b 让门槛从"有一个证据"抬到"两个都要有"。

易错：b 不是"阈值"。真正的判定发生在 ReLU 里（拿 0 当分界），b 只是平移了那个分界的位置。
激活函数activation function，记作 f§3.3 式(2) 中的 ReLU

是什么：加权求和之后套的那个固定函数。论文用的是 ReLU：max(0, x)。

为什么必须有：不加它，整个网络就退化成一个大的线性函数（下一节会用数字证明）。

还有哪些：sigmoid、tanh、LeakyReLU、GELU。它们形状不同，作用都是"插入非线性"。

4为什么"不加激活函数就不行"：用数字算给你看

假设某一层只做 y = w·x + b，不做任何弯折。第一层 w₁=2, b₁=1；第二层 w₂=3, b₂=0。

把第一层的输出代进第二层：

y = 3 × (2x + 1) + 0 = 6x + 3

这等价于一层 w=6, b=3 的线性层。也就是说，两层叠起来，除了"参数变多"，表达能力一点没涨。

推到一百层也一样：不管叠多少层，最后都能压成一个 y = Wx + B。这就是为什么必须每隔一段插一个非线性函数—— 它把直线掰弯，让后面的层有机会表达"非直线"的关系。

ReLUrectified linear unit§3.3 式(2)

公式：ReLU(x) = max(0, x)。正数原样，负数归零。

形状：先是一条水平的线（x<0 时恒为 0），到 0 突然拐一个角，然后是一条斜率 1 的直线。

为什么论文选它：算得快（只比大小，不做指数），而且不会像 sigmoid 那样在两端"饱和"（梯度接近 0，学不动）。

易错：ReLU 在 x=0 处有一个尖角，不可导。实际实现里约定该点导数为 0 或 1，不影响训练。
GELUGaussian error linear unit本文没有使用；BERT、GPT 使用

是什么：ReLU 的平滑版本——不是"负的全砍掉"，而是"负的按比例缩小，越负压得越狠"。

为什么会有它：ReLU 那个尖角让函数在 0 附近不够光滑。GELU 用一条平滑曲线代替它， 整体形状和 ReLU 很像，但处处可导、过渡更柔和。

和本文的关系：论文里没有 GELU（它 2016 年提出，但 Transformer 原文用的是 ReLU）。 后来的 BERT、GPT 系列改用 GELU，效果略好。你如果在别的资料里看到 GELU，那是后续模型的改进，不是这篇论文的内容。

易错：GELU 和 ReLU 的差别是"平滑程度"，不是"有没有非线性"。两者都能提供非线性，把 FFN 换成 GELU 不会改变架构，只是换了一个更光滑的弯折。

5一个神经元的极限：它只能画一条直线

把输入缩到两个数，就能画在平面上。一个神经元做的事，本质上是在平面上画一条直线，把两边分开： 线的一侧输出正数（ReLU 后不为 0），另一侧输出 0。

这个限制看起来很弱。有些问题，一条直线永远分不开。

一个具体的反例

任务：判断"两个信号是不是不一样"。

x₁x₂算不算"不一样"
00不算（两个都没有）
11不算（两个都有）
10算
01算

画在平面上，(0,0) 和 (1,1) 在左下和右上，(1,0) 和 (0,1) 在左上和右下。 两类点是交叉的——你没法用一条直线把两个对角圈在一起、另外两个分开。这就是著名的 XOR 问题。

历史上的事：1969 年 Minsky 和 Papert 在《Perceptrons》里指出单层感知机连 XOR 都做不了。 这个结论让神经网络研究冷了将近二十年，史称第一次 AI 寒冬。解法其实很简单——加一层。

6加一层为什么就解决了：换个坐标系看问题

关键思路不是"画更多直线"，而是把点搬到新位置，让它们变得可分。

在中间插一层，把原来的两个坐标换成两个新坐标：

新坐标① = x₁ + x₂　（两个信号加起来有多少）
新坐标② = 两个信号差多少

四个点搬过去之后：

原来的点新坐标类别
(0, 0)(0, 0)不算
(1, 1)(2, 0)不算
(1, 0)(1, 1)算
(0, 1)(1, 1)算

搬完之后，两类点的"第二个坐标"完全不同：不算的一组全是 0，算的一组全是 1。 这时一条水平直线就能把它们分开——问题从"分不开"变成了"很容易分"。

隐藏层hidden layer§3.3 FFN 的中间 2048 维

是什么：夹在输入和输出之间的那一层。它不直接对外输出，作用是把输入换一种表示。

为什么要它：原始输入往往"不好分"。换一套坐标之后，原本纠缠在一起的类别被拉开，后面的层就容易处理了。

代价：维度通常比输入大。FFN 里 512 维的输入先被拉到 2048 维（4 倍），加工完再压回 512 维。

易错："隐藏层"不是"看不见的层"。它的输出是实实在在的数字，只是不直接作为最终结果。你完全可以把中间层的激活值打印出来看。

这个"把输入换一个更好用的坐标"的过程，有个正式名字叫表示学习（representation learning）。 深度网络的威力，主要不来自"层数多"，而来自每一层都在为下一层重新组织表示。

7从一个神经元到一个网络：宽、深、参数

把很多神经元并排放，就成了一层；把很多层叠起来，就成了一个网络。三个词描述它的规模：

宽度width / 维度 dd_model = 512，d_ff = 2048

是什么：每一层里有多少个神经元，也就是这一层输出几个数字。

本文的数：主干上所有表示都是 512 维；FFN 中间那一层是 2048 维。

深度depth / 层数 NN = 6

是什么：同样的结构重复几次。论文里编码器堆 6 层、解码器堆 6 层。

参数量parameter countbase 约 6500 万

怎么数：把所有权重和偏置加起来。一个 512 维 → 2048 维的线性层， 权重矩阵是 512×2048 = 1,048,576 个数字，加上 2048 个偏置，约 105 万个参数。

感受一下：FFN 里这样一次"升维 + 降维"要两个矩阵，合计约 210 万个参数。 模型有 12 层（编码器 6 + 解码器 6），每层都有一个 FFN——这就是为什么 §3.3 说"FFN 占了参数的大头"。

8小结

本页要点

  1. 一个神经元 = 加权求和 + 偏置 + 激活：f(x₁w₁ + … + b)，没有别的机关。
  2. 权重决定信号多重要，偏置决定门槛高低，两者都是训练学出来的。
  3. 激活函数必须有：没有它，多少层线性层叠起来都等价于一层（3×(2x+1) = 6x+3）。
  4. 单个神经元只能画一条直线，连 XOR 都做不了；解法是加隐藏层，把点搬到新坐标系。
  5. ReLU 是本文用的激活（负的归零）；GELU 是后来的平滑替代品，本论文没用。
  6. 规模用三个词描述：宽 512 / 深 6 / 参数 6500 万。参数集中在 FFN 的 512↔2048 两个矩阵里。

9自测

Q1某个神经元 w₁=1.0、w₂=1.0、b=−0.5，输入 x₁=1、x₂=0。经过 ReLU 后输出是？
先求和：1.0×1 + 1.0×0 = 1.0；加偏置：1.0 − 0.5 = 0.5；ReLU(0.5) = 0.5。注意 ReLU 只砍负数，正数原样通过。
Q2如果把 Transformer 里所有激活函数都去掉，只保留线性层和注意力，会发生什么？
线性层叠线性层仍是线性层；注意力里的加权平均本身也是线性的（权重由 softmax 算出，但混合这一步是线性的）。所以 ReLU 是非线性的唯一来源，删掉后整体退化。
Q3关于本文用的激活函数，说法正确的是？
原文 §3.3 式(2) 明确写的是 ReLU。GELU 2016 年提出，Transformer 原文没有采用；后续模型换用它是因为更平滑、效果略好。
Q4为什么说"单个神经元只能画一条直线"？
加权求和 x·w + b = 0 定义的就是一个超平面（二维时是一条直线）。输入规模再大，也只是一个高维平面，分不开 XOR 那种交叉分布。
Q5FFN 里把 512 维升到 2048 维再降回 512，升维这一步的作用最准确的描述是？
升维提供"更大的工作台"，让非线性有空间把特征重新组合；降维是为了回到 512 维才能和残差相加。维度对齐是降维的目的，不是升维的。
原文出处 §3.3 Position-wise Feed-Forward Networks（式 2：两层线性变换 + 中间 ReLU，dff=2048）； §3.1 编码器/解码器各 N=6 层；表 3 参数总量 65M。XOR 与感知机局限属背景知识，原文未涉及。
